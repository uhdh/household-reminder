# UI 디자인 진행 상황

`chore-planner-mockup.html`은 실제 앱 코드가 아니라, 홈 화면 UI 방향을 정하기 위해 만든 정적 목업입니다. 브라우저로 그냥 열면 동작합니다 (더블클릭 또는 `file://` 열기).

## 지금까지의 디자인 반복

1. "냉장고 마그넷 메모보드" 콘셉트 → 반려
2. Apple Reminders 스타일 (체크박스 리스트) → "직관적이지 않다"는 피드백으로 반려
3. **iOS 홈 화면 아이콘 그리드 (현재 방향)** — 각 집안일을 앱 아이콘처럼 타일로 나열하고, 탭하면 완료 처리(=초기화)되는 방식. 처음엔 사용자가 준 인포그래픽 이미지를 오려서 썼지만, "이미지는 키워드에 맞게 다시 그려달라"는 요청으로 손으로 그린 SVG 라인 아이콘 19종으로 교체함.

## 현재 확정된 UI 방향

- 홈 화면 = 모든 집안일 항목을 4열 아이콘 그리드로 표시 (iOS 홈스크린처럼)
- 밀린 항목은 아이콘 우측 상단에 **빨간 숫자 배지**(며칠 지났는지)로 표시. 안 밀렸으면 배지 없음
- 아이콘을 탭 = 완료 처리 (체크 애니메이션 후 배지 사라짐, 마지막 완료일이 오늘로 갱신)
- 우측 상단 "편집" → 아이콘이 흔들리며(iOS 홈스크린처럼) 좌상단에 삭제(−) 버튼 표시
- "+" 타일로 새 항목 추가: 이름 / 주기(N일·주·개월) / 아이콘 선택
- 아이콘은 `ICON_LIB` 객체(파일 내 `<script>`)에 SVG path 형태로 정의되어 있어 재사용 가능 (라이브러리/이미지 파일 의존성 없음)
- 라이트/다크 테마 모두 지원

## 기존 계획과 달라진 점

`C:\Users\maktu\.claude\plans\gentle-chasing-sonnet.md`에 저장된 최초 아키텍처 계획(Next.js + TypeScript + SQLite + Tailwind, `lib/chores.ts` 마감일 계산 로직 등)은 여전히 유효합니다. 다만 그 계획의 "홈 화면" 절은 "마감 지난 항목만 리스트로 표시"였는데, 디자인을 거치며 **"전체 항목을 아이콘 그리드로 보여주고, 밀린 것만 배지로 강조"**하는 방식으로 바뀌었습니다. 실제 구현 시 이 목업의 인터랙션과 아이콘을 기준으로 삼으면 됩니다.
